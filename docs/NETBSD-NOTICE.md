# NetBSD controller initialization attribution

The controller bootstrap adapts NetBSD hci_unit.c and hci_event.c.
The ACL receive and transmit adapters also derive from NetBSD hci_link.c,
with transmit completion accounting adapted from hci_event.c.
The outgoing ACL connection state machine adapts both of those sources too.
The command scheduler also adapts hci_unit.c and hci_event.c.
The following notice applies to that derived code, including its legacy
command mask. Other upstream files retain their individual notices.
